Workflow and Scripts for analysis of RNA-Seq data to identify transcriptional responses underlying mutualistic association between anemone and anemonefish.

1. RNA-Seq_data_QC_and_trnascriptome_assembly has all the scripts for the initial QC of the RNA-seq data, mapping the reads to the A. clarkii reference genome, construction of the de novo transcriptome assembly of E. quadricolor and mapping the E. quadricolor reads to the transcriptome assembly.

2. anemone_DE.R has all the scripts for differential expression analysis of the E. quadricolor data.

3. Skin_DE_analysis.R has all the scripts for differential expression analysis of the A. clarkii skin data.

4. clarkii_brain_DE.R has all the scripts for differential expression analysis of the A. clarkii brain data.
